# Movie Land

Movie Land is a Persian website for reading and sharing movie and series reviews.

I built this project while learning React and used it to practice building a real frontend project from scratch. The project includes multiple pages, article categories, article details, responsive layouts, and a simple form for submitting articles.

## Technologies

* React
* JavaScript
* Vite
* React Router DOM
* Axios
* CSS
* JSON Server

## Features

* Home page with a hero section
* Article list and article details
* Movie and series categories
* Article submission page
* Responsive design
* Mobile navigation menu
* Client-side routing with React Router
* Fetching article data with Axios
* Local API using JSON Server

## Getting Started

Clone the repository:

```bash
git clone https://github.com/ashirzadian3-prog/movie-land.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

To run the local API:

```bash
npx json-server data/db.json --port 8000
```

The API will be available at:

```text
http://localhost:8000/articles
```
